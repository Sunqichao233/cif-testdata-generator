# CIF情報ファイル テストデータ生成ツール / CIF信息文件 测试数据生成工具

Amazon WorkSpaces 上で、設計書「CIF情報ファイルの項目」に準拠したテストデータ
（タブ区切り13項目 / 1レコード）を生成・自己検証するためのツール一式です。

> **中文速览**
> - Windows / Amazon WorkSpaces 上双击 `run_generate.bat` 生成符合规格书的测试数据（Tab 分隔 13 列）。
> - 生成后自动按项目定义校验（位数・字符种・必填・重复・日期），全部通过输出 `結果 : OK`（退出码 0）。
> - 设计书为**中日对照**：`docs/CIF情報ファイル_テストデータ設計書.xlsx`（6 个 sheet，45 条测试用例）。
> - 参考数据（复现实际数据画面的匹配模式 18 条）在 `samples/` 下，详见第 7 节。

## 4. クイックスタート / 快速开始

1. 本フォルダ一式を WorkSpaces 内の `D:\work\cif-testdata\` などにコピーする
2. `config\config.json` の `count` と `butenCode` を確認する
3. `run_generate.bat` をダブルクリックする
4. メニューから `[1]` を選択する
5. `結果 : OK` が表示され、`output\` にファイルが出力されることを確認する

```
[1] Standard   - minimal profile  (No.1 / No.3 / No.13 only)
[2] Full       - all 13 fields filled
[3] Full + boundary records (max length rows appended)
[4] Matching   - collation patterns 2x3x3 = 18 records
[5] Custom record count
[6] Validate existing files only (no generation)
[7] Open output folder
[0] Exit
```

## 5. コマンドライン実行 / 命令行执行

```bat
rem 既定設定で生成 / 按默认设置生成
run_generate.bat

rem 全ファイル 500 件ずつ、全13項目 / 每个文件 500 条，全 13 列
run_generate.bat -Count 500 -DataProfile full

rem 境界値レコードを末尾に付加 / 末尾追加边界值记录
run_generate.bat -DataProfile full -IncludeBoundary

rem 照合パターン18件（実データ再現）/ 匹配模式 18 条（复现实际数据）
run_generate.bat -DataProfile matching -Target 002

rem CIF の 001 / 002 のみ、UTF-8 で生成 / 仅 001、002，UTF-8 编码
run_generate.bat -Target 001,002 -Encoding utf-8

rem 生成せず検証のみ / 不生成，仅校验
run_generate.bat -ValidateOnly
```

## 8. 自動検証の内容 / 自动校验内容

生成直後（および `-ValidateOnly` 実行時）に、出力ファイルを読み直して次を検査します。

- 1レコードの項目数が **13**（`extraColumns` 有効時は 13＋n）であること / 列数正确
- 可変長項目：**最大桁数以内** / 可变长列不超过最大位数
- 固定長項目（No.8 / No.9 / No.12）：**桁数が完全一致** / 固定长列位数完全一致
- 文字種（`c` / `k` / `j` / `n`）に適合 / 符合字符种
- 必須項目（No.1 レコードID、No.13 部店コード）が設定済み / 必填项已设置
- 名称（フリガナ / 漢字 / 英字）のうち **少なくとも1項目**が設定済み / 名称至少设置一项
- No.1 レコードIDが**同一ファイル内で重複していない** / 记录ID 文件内不重复
- No.3 名称（フリガナ）が**同一ファイル内で重複していない** / 片假名名称文件内不重复
  ※ `matching` プロファイルでは意図的に重複するため自動的に無効化 / matching 配置下自动关闭
- No.1 レコードIDに**後続スペースが残っていない** / 记录ID 无尾部空格
- No.12 設立/生年月日が **YYYYMMDD の実在する日付** / 出生日期为真实存在的日期
- 空行が含まれていない / 无空行

検出時はコンソールに先頭20件、ログファイルに全件を出力し、終了コード `1` で終了します。

```
[NG]   L2 No.9 国内郵便番号 : 固定7桁ではありません (実際: 8)
[NG]   L2 No.12 設立/生年月日 : 存在しない日付です (20260230)
[NG]   L2 No.1 レコードID : ファイル内で重複しています (0000000001)
[NG]   L4 No.3 名称（フリガナ） : ファイル内で重複しています (ヤマダ タロウ)
```

```jsonc
      // … No.15〜No.21 も同様 …
      { "no": 22, "name": "未確定（実データでは契約番号形式）", "value": "A100000001-01" },
      { "no": 23, "name": "未確定（実データでは1桁フラグ）",   "value": "0" }
    ]
  },

  // 照合パターン(2x3x3=18)の値 / 匹配模式取值
  "matching": {
    "butenCodeOverride": "0011",       // "" にすると targets の butenCode を使用
    "furigana": { "A": "アイダマナ", "B": "アイタナナ" },
    "kanji":    { "A": "相田　マナ", "B": "相他ナナ", "C": "" },
    "birthday": { "A": "20000101",   "B": "20010101", "C": "" }
  },

  "targets": [
    { "id": "001", "kind": "cif", "label": "…", "butenCode": "0005", "count": 100, "enabled": true }
    // kind: "cif" | "search"、enabled: false で生成対象から除外
  ],
  "validation": {
    "enabled":                true,
    "stopOnError":            false,  // true で最初のNGで処理中断
    "checkDuplicateRecordId": true,
    "checkDuplicateFurigana": true
  }
}
```

> **全角文字で桁数エラーになる場合**：取込システムがバイト数で桁数を判定しているなら
> `generation.lengthCheckMode` を `"byte"` に変更してください（Shift_JIS のバイト数で判定）。
> **若全角字符导致位数错误**：若导入系统按字节数判定，请将 `lengthCheckMode` 改为 `"byte"`。

## 10. 異常系テストデータの作り方 / 异常数据的制作方法

本ツールは **正常系・境界値（正常）・照合パターン** のデータを生成します。異常系は生成済みファイルを編集して作成します。
本工具生成**正常系・边界值・匹配模式**数据；异常数据需编辑生成后的文件。

1. `run_generate.bat` で正常データを生成する / 先生成正常数据
2. `output\` のファイルをコピーし、Shift_JIS 対応エディタ（サクラエディタ等）で開く / 复制并用支持 Shift_JIS 的编辑器打开
3. 設計書「3.テストケース一覧」で **生成方法＝手動編集** のケースの値に書き換える / 按设计书改写取值
   （レコードID重複、31桁超過、郵便番号にハイフン、`20260230`、項目数12/14 など）
4. `run_generate.bat -ValidateOnly` を実行し、**想定どおりのエラーが検出される**ことを確認 / 确认能检出预期错误
5. 対象システムへ投入し、期待結果と一致するか確認して Excel の「結果」欄に記入 / 导入并填写结果栏

## 12. トラブルシューティング / 故障排查

| 事象 / 现象 | 対処 / 处理 |
| --- | --- |
| コンソールの日本語が化ける / 控制台日文乱码 | コンソールのフォントを「ＭＳ ゴシック」等に変更 |
| 生成ファイルが化ける / 生成文件乱码 | `output.encoding` を取込システムの仕様に合わせる |
| 「このスクリプトは実行できません」/ 提示无法执行脚本 | `run_generate.bat` 経由で起動する |
| `ファイルが見つかりません` / 找不到文件 | `run_generate.bat` / `scripts` / `config` を同一構成のまま配置する |
| 全角文字で桁数エラー / 全角导致位数错误 | `generation.lengthCheckMode` を `"byte"` に変更 |
| 項目数エラーになる / 提示列数错误 | 実データが13項目でない場合は `extraColumns` を有効化 |
| 照合パターンでフリガナ重複エラー / 匹配模式片假名重复 | `matching` では自動的に重複チェックを無効化（対処不要） |
| フリガナが重複する（通常データ）/ 片假名重复 | 姓20×名20＝400通り。400件超はカナ連番が自動付加される |
| WorkSpace 再起動でファイルが消えた / 重启后文件消失 | C ドライブは初期化される。D ドライブ配下に配置する |
| Excel 生成で `PermissionError` | 対象の .xlsx を Excel で開いている。閉じてから再実行 |
| 実行ログを確認したい / 查看日志 | `logs\generate_yyyyMMdd_HHmmss.log`（UTF-8 BOM付） |

## 13. 注意事項 / 注意事项

- 生成されるのはすべて**ダミーデータ**ですが、氏名・住所形式は実データに準じるため、取扱いは案件のデータ管理ルールに従ってください。/ 全部为**虚拟数据**，但格式贴近真实数据，请按项目数据管理规则处理。
- 試験完了後は `output\` 配下のファイルを削除してください。/ 测试完成后请删除 `output\` 下的文件。
- `No.8 ID情報種類` のコード値（`01`〜`05`）は暫定値です。正式値は導入時のヒアリングシートで確定してください。
- `No.11 英文住所` にはリストの都市・住所と照合するため**国名を含めません**（設計書 備考に準拠）。
- `No.13 部店コード` は設計書では `0005` / `LF003` / `LF004` ですが、**実データ画面では `0011`** でした。案件の確定値を必ず確認してください。/ 规格书与实际数据不一致，请务必确认。
- `No.14` 以降の項目定義は**未入手**です。参考データの該当列は推定値です。/ `No.14` 之后的定义**未获取**，参考数据中相应列为推定值。
