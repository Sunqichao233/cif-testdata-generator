libInfo 変換ツール

使い方

  1. libInfo のファイルを 「ここにlibInfo.txtをドラッグ＆ドロップしてください.bat」 に乗せる
  2. 調査結果が出るので確認する（★が付いた項目は要注意）
  3. 問題なければ Y を押す

出力

output フォルダに2つできます。

ファイル内容
（元の名前）_変換後_YYYYMMDDHHII.txt変換結果（タブ区切り）
（元の名前）_変更ログ_YYYYMMDDHHII.txt削除した行の一覧

ファイル名の末尾は実行日時です。実行するたびに別ファイルになります。

手作業の結果と比べる

script フォルダの compare.bat をダブルクリックします。
手作業の正解ファイルは、ツールのフォルダに置いてください。

設定を変える

script\convert.ps1 の先頭に、文字コード・削除キーワードなどがあります。

入力ファイルは Shift_JIS で読みます。出力も Shift_JIS です。
