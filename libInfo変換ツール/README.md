# libInfo.txt 変換ツール（テキスト → テキスト。Excel 不要）

## 使い方

1. `libInfo.txt` を **`run.bat`** にドラッグ＆ドロップ（または同じフォルダに置いて `run.bat` をダブルクリック）
2. まず調査結果が出ます。★が付いた項目を確認してください（特に「'folder' を含む行」が 0 でないとき）
3. 問題なければ `Y` を押すと **`libInfo_converted.txt`** が作られます（タブ区切り / Shift_JIS）

- `old` のみに該当した行は**既定で削除**し、`_old_candidates.txt` に記録を残します。削除したくない場合は `-KeepOld`
- 出力の文字コード、削除キーワードの変更 → `convert.ps1` の先頭のパラメータと `$Patterns`
- 行末スペース：既定は `-TailSpace manual`（1個だけ削除。**手作業の正解と1バイトも違わない**）／`all` は全削除
- 削除パターンに当たるが消してはいけない行 → `convert.ps1` の `$KeepPatterns`
  登録済み：`AfterRcv_org.bat`（`org.` に当たるが手作業の正解では残っている正規のバッチ）
- 手作業の `_変換後.txt` との突き合わせ → **`compare.bat`** をダブルクリック（「手順」⑦ 結果検証）
  レポートは1画面に収まる長さ（`compare_report.txt`）。全明細が要るときは `-Full`

## スクリプトの関係

```
run.bat
  │
  ├─① convert.ps1 -Mode check     調査のみ。ファイルは作らず結果を表示
  │
  │   ……Y を押すと続行（他のキーなら何もせず終了）
  │
  └─② convert.ps1 -Mode convert   変換を実行し、テキストを出力

compare.bat ─> compare.ps1         run.bat からは呼ばない。必要なときに実行
```

- **`run.bat`** は起動用。PowerShell の場所を探し、ファイルパスを渡し、間に Y/N を挟むだけ。処理ロジックは持たない
- **`convert.ps1`** が本体。`-Mode check` と `-Mode convert` は同じ判定を通り、違いは「最後にファイルを書くかどうか」だけ
- そのため ② では ① と同じ調査結果がもう一度表示される。不具合ではなく、実行結果にエビデンスを残すため
- **`compare.ps1`** は変換とは無関係。「スクリプトの出力 vs 手作業の正解」の差分だけを見る

## convert.ps1 の処理の流れ

```
読込（Shift_JIS）
  → 1行目を捨てる
  → 1行ずつ判定：削除パターン11個のいずれかに当たれば捨てる（パターン別に集計）
  → 残った行：半角スペース3つ → タブ   …手順書(1)
              行末スペースの処理        …手順書(8)
  → 書き出し（タブ区切り）
```

削除パターン11個：
`\log\` `\save\` `\common\tools\JudgedCIF\data\output` `コピー`
`bk.` `_bk` `bkup` `bak` `org.` `old` `origin.txt`

すべて**大文字小文字を区別しない文字列比較。正規表現は使わない** ——
正規表現にすると `bk.` `org.` の `.` が任意1文字になり、
手順書で「対象外」と明記されている `ORGXX` まで削除してしまうため。

## 文字コード

| ファイル | 文字コード | 理由 |
| --- | --- | --- |
| `*.ps1` | UTF-8（BOM 付き） | PowerShell 5.1 は BOM が無いと日本語が化ける |
| `*.bat` | Shift_JIS | コマンドプロンプトは OS のコードページで解釈するため |
| 入力 `libInfo.txt` | Shift_JIS | 手順書の指定 |
| 出力 `*_converted.txt` | Shift_JIS | ※未確認。変更は `convert.ps1` の `-OutCharset` |

## 申し送り事項

- **`AfterRcv_org.bat` を例外に登録した根拠は「手作業の正解で残っていたから」**であり、手順書には記載がない。
  手順書の備考は `PKG標準資材の"〜ORGXX"は対象外` のみで、この2ファイルは `ORGXX` の形ではない。
  例外の規則（このファイル名だけなのか、`\common\batches\` 配下すべてなのか）を手順書に追記することを推奨。
- **手順書(8)の「置換の繰返し」が未チェック**のため、サクラエディタの すべて置換 は行末スペースを1個しか消さない。
  一方で注記は「★末尾の半角スペースを削除する★」となっており、意図と設定が食い違っている。
  本ツールは既定で手作業の結果を再現（`-TailSpace manual`）している。
- **`old` は部分一致**のため `folder` `holder` なども巻き添えになる。
  調査結果の「'folder' を含む行」が 0 でない場合は要確認。
