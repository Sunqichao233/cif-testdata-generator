--- ③ 全銀協（個人）のリストが実際に取り込まれているか -------------
SELECT r.lst_id, o.origin, o.origin_jp, r.list_num, r.last_reg_date
  FROM lst_reg_tbl r
  JOIN mst_lstorigin_tbl o ON o.lst_id = r.lst_id
 WHERE r.lst_id IN (4,5,6,7,8)
 ORDER BY r.lst_id;

   lst_id=7（ASI 全銀協（個人））の list_num が NULL や 0 なら
   リスト自体が入っていない。26 を直してもヒットしない。


--- ④ リスト発行元の設定（個人／法人の別・有効かどうか）------------
SELECT lst_id, origin, origin_jp, is_disp, is_check, is_com_check,
       filtering_def_id, threshold
  FROM mst_lstorigin_tbl
 ORDER BY lst_id;

   is_check='Y'      → 個人の照合対象
   is_com_check='Y'  → 法人の照合対象
   lst_id=7 は is_check='Y' / is_com_check='N'（個人専用）のはず。


--- ⑤ 25：部店フィルタリング（こちらは実機は正しいはず。念のため）----
SELECT filtering_def_id, count(*) AS unit_cnt
  FROM cnf_unit_filtering_tbl
 WHERE filtering_def_id IN (6,7)
 GROUP BY filtering_def_id
 ORDER BY filtering_def_id;

   6 が 0件、7 が 596件 なら正しい。
