# CIF 测试数据生成脚本

生成 Tab 分隔 27 列的 CIF 测试数据，UTF-8 输出，最多 40000 条。

---

## 1. 怎么生成

双击 `run.bat`，或者在命令行里：

```bat
run.bat                        生成 1 条（用来和「正确的数据」对照）
run.bat 40000                  生成 4 万条
run.bat 100 kana               姓名用片假名（サトウ　イチロウ）
run.bat 100 kanji 20260929     再指定文件名里的日期
```

参数是 `run.bat [条数] [姓名类型] [日期]`，都可以省略。

- **条数**：1 ～ 40000。超过会直接报错，不会偷偷截断
- **姓名类型**：`kanji`（默认，汉字）或 `kana`（片假名）。**二选一，不混用**
- **日期**：只影响输出的文件名，不影响数据里的生日

生成结果在 `output\` 目录下。画面上会把第 1 条的 27 列逐列列出来，对照一下就知道对不对。

## 2. 怎么改 ★重点

### 2-1. 改文件名

打开 **`run.bat`**，找到最上面的「配置区」：

```bat
rem ---- 输出文件名 ----
rem   留空 = 自动用 CIF_<日期>.txt
rem   想固定文件名就写死，例如：set "FILENAME=U2KJD001"
set "FILENAME="
```

- **留空**（默认）→ 文件名是 `CIF_20260925.txt` 这种，日期自动取当天
- **想固定文件名** → 写成 `set "FILENAME=U2KJD001"`，就会输出 `U2KJD001`（注意：这样写**没有扩展名**，HULFT 的文件名经常是这样的）
- 想带扩展名就写 `set "FILENAME=U2KJD001.txt"`

顺便，输出目录也在同一个配置区：

```bat
set "OUTDIR=%~dp0output"
```

`%~dp0` 是 bat 自己所在的目录。想直接输出到别的地方就改成绝对路径，例如 `set "OUTDIR=C:\FileRCV\output"`。

### 2-2. 改店铺代码（LF003）

打开 **`layout.csv`**，找第 13 行：

```
13,部店コード,固定,LF003,★店铺代码。要改就改「値」这一格
                  ↑↑↑↑↑
                改这里就行
```

改成 `LF004`、`0011` 之类的都可以。改完直接跑，不用动脚本。

### 2-3. 改日期

同样在 `layout.csv`，第 12 行：

```
12,生年月日,日付,2000,「値」=年份。生成该年份里的某一天
                ↑↑↑↑
```

- **「値」写年份**（如 `2000`）→ 生成那一年里的日期，按天循环铺开。2000 年是闰年，所以是 366 种，4 万条的话每天大概 109～110 条
- **想固定成某一天** → 把「種別」从 `日付` 改成 `固定`，「値」写完整的 8 位日期：

```
12,生年月日,固定,20000101,
```

### 2-4. 改某一列的内容 / 加一列

**全部在 `layout.csv` 里改，不用碰脚本。**

「種別」只有这 6 种：

| 種別 | 作用 | 「値」写什么 |
| --- | --- | --- |
| `固定` | 固定值，每条都一样 | 值本身，如 `LF003` |
| `序号` | 递增号 | 位数，如 `6` → `000001` |
| `日付` | 某年里的某一天 | 年份，如 `2000` |
| `姓名漢字` | 自动生成的汉字姓名 | 不用写 |
| `姓名カナ` | 自动生成的片假名姓名 | 不用写 |
| `空` | 留空 | 不用写 |

**把空列改成有值**：把那一行的 `空` 改成 `固定`，「値」填内容。

```
改前： 7,,空,,
改后： 7,備考,固定,TEST,
```

**加一列**：在最后加一行，列号必须接着往下排。

```
28,新項目,固定,ABC,
```

列号不连续的话脚本会报错并告诉你哪里断了，不会生成错误的文件。

**删一列**：删掉那一行，然后**把后面所有行的列号往前挪**，保持连续。

### 2-5. 改姓名（加人名素材）

姓名来自 **`names.csv`**：

```
種別,漢字,カナ
姓,佐藤,サトウ
名,太郎,タロウ
```

现在是 **姓 205 × 名 200 = 41000 种组合**。

因为要求「姓名里不能有数字」，所以不能靠加后缀凑数 —— **能生成的条数上限就等于组合数**。要生成超过 41000 条，就得往 `names.csv` 里加「姓」或「名」的行。条数不够时脚本会明确报错提示。

### 2-6. 改递增号的起点

`run.bat` 配置区：

```bat
rem ---- 递增序号的起始值（默认从 1 开始）----
set "STARTNO="
```

写 `set "STARTNO=1000"` 就从 `001000` 开始。分批生成、不想和上一批号码重复时用得上。

## 3. 文件说明

| 文件 | 作用 | 要不要改 |
| --- | --- | --- |
| `run.bat` | 入口。文件名、输出目录、起始号在这里配 | 改文件名时 |
| `layout.csv` | **27 列的定义**。每列填什么都在这里 | 改内容时主要改这个 |
| `names.csv` | 姓名素材（姓 205 + 名 200） | 要更多条数时加行 |
| `make_cif.ps1` | 生成本体 | 一般不用动 |
| `output\` | 生成结果 | — |

编码：`run.bat` 是 UTF-8 无 BOM，其余是 UTF-8 带 BOM。
CSV 存成 Shift_JIS 也能跑（脚本会自动判别编码），但建议保持 UTF-8。

## 4. 输出格式

Tab 分隔、27 列、CRLF 换行、UTF-8。27 列里**实际有值的是 7 列**：

| 列 | 内容 | 例 |
| --- | --- | --- |
| 1 | レコードID（递增） | `000001` |
| 2 | タイプ（固定 I＝个人） | `I` |
| 3 | 名称（フリガナ） | 二选一 |
| 4 | 名称（漢字） | `佐藤　太郎` |
| 5〜11 | 空 | |
| 12 | 生年月日（2000年的某一天） | `20000101` |
| 13 | 部店コード | `LF003` |
| 14〜25 | 空 | |
| 26 | レコードID2（同第1列） | `000001` |
| 27 | 削除タグ（固定 0） | `0` |

第 3 列和第 4 列是**二选一**：`kanji` 模式填第 4 列、第 3 列留空；`kana` 模式反过来。所以有值的列永远是 7 个。

生成出来长这样（`→` 是 Tab）：

```
000001→I→→佐藤　太郎→→→→→→→→20000101→LF003→→→→→→→→→→→→→000001→0
```

姓和名之间是**全角空格**（U+3000），不是半角。

## 5. 怎么确认生成对不对

### 5-1. 看画面

脚本跑完会把第 1 条按列切回来显示：

```
    列 項目名                種別         内容
    1 レコードID             序号         000001
    2 タイプ                固定         I
    3 名称（フリガナ）           姓名カナ       (空)
    4 名称（漢字）             姓名漢字       佐藤　太郎
   ...
  切出来 27 列 -> OK
```

列数对不上会直接标 NG。

### 5-2. 看文件

VSCode 直接打开就行（UTF-8）。**不要**用「显示空白字符」以外的方式判断 Tab —— Tab 在编辑器里看起来就是一片空白，很容易数错。

想数清楚的话，在 VSCode 里按 `Ctrl+Shift+P` → `Toggle Render Whitespace`，Tab 会显示成 `→`。

## 6. 常见问题

**Q. 打开文件全是乱码**
A. 确认编辑器是按 UTF-8 打开的。VSCode 右下角能切换编码。

**Q. 条数报错「组合数不够」**
A. 姓名不能带数字，所以条数不能超过 `names.csv` 的组合数（现在是 41000）。往 `names.csv` 加「姓」或「名」的行。

**Q. 提示「列号不连续」**
A. `layout.csv` 的第一列必须是 1,2,3… 连着排。删行之后要把后面的号往前挪。

**Q. 名字为什么不重复也不扎堆**
A. 脚本用一个和组合数互质的步长跳着取姓名组合，既走遍全部组合不重复，又不会出现「佐藤　太郎 / 鈴木　太郎 / 高橋　太郎…」连着 205 条同名的情况。实测连续相同的姓和名都是 1 条。

**Q. 生成 4 万条要多久**
A. 约 1 秒。

## 7. ⚠️ 待确认事项

**列数是 27 还是 25**

要求书里两处说法不一致：

| 依据 | 列数 | Tab 数 |
| --- | --- | --- |
| 表（1〜27 逐条列举） | **27** | 26 |
| 下面的 `[Tab]` 实例 | 25 | 24 |

表里写 `4~11 空（8个）` 需要 9 个 Tab，实例只有 8 个；`14~25 空（12个）` 需要 13 个，实例只有 12 个。两处各少 1 个 —— 连续 Tab 在复制粘贴时容易被吃掉，所以**按表（27 列）做的**。

如果实际是 25 列，删掉 `layout.csv` 里 2 行空列、把后面的列号挪一下就行，脚本不用动。

**日期的年份**

要求书表里写 `20000101`、文字说明写「2000年的某一天」，但下面的 `[Tab]` 实例里是 `19700101`。按前两者做的（2000 年）。要改成 1970 就把 `layout.csv` 第 12 行的「値」改成 `1970`。
